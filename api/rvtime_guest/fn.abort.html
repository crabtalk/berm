pub fn abort() -> !
Expand description

Stop the guest, reporting a breakpoint trap to the host.

Use this as the body of #[panic_handler]. The obvious alternative — loop {} — hangs the thread the host called in on, which for an embedder running many guests is far worse than a trap it can catch and report.

ⓘ
#[panic_handler]
fn panic(_: &core::panic::PanicInfo) -> ! {
    rvtime_guest::abort()
}
