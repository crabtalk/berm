Jalr

jalr rd, imm(rs1) — jump and link register.

rd == ra is a call, rd == zero && rs1 == ra && imm == 0 is a return, and rd == zero otherwise is a tail call or computed jump.

Unimp

unimp — the defined illegal instruction.

The all-zero halfword is guaranteed by the ISA to trap, and compilers emit it deliberately where control must not reach: after a diverging call, or for an unreachable branch. It is a real instruction meaning “stop here”, not undecodable input.
