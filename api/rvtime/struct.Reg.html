Struct Reg 

pub struct Reg(/* private fields */);
Expand description

Guest registers, re-exported for host functions that work on them directly. A RISC-V general-purpose register, x0..x31.

x0 is hardwired to zero; the translator relies on Reg::is_zero to fold reads to a constant and drop writes.
