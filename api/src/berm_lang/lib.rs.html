1//! Build a Crabtalk harness.
2//!
3//! A harness is code the daemon schedules: one RV64IMAC ELF, confined to its
4//! own address space, reaching the world only through host calls it was
5//! granted. This crate is what an author writes against — it owns the ABI so
6//! they never see a call number, a register, or a pointer pair.
7//!
8//! ```ignore
9//! #![no_std]
10//! #![no_main]
11//!
12//! #[berm_lang::harness]
13//! mod tools {
14//!     use berm_lang::{Failed, Out};
15//!
16//!     /// Echo the argument blob back.
17//!     pub fn echo(args: &[u8], out: &mut Out) -> Result<(), Failed> {
18//!         out.write(args);
19//!         Ok(())
20//!     }
21//! }
22//! ```
23//!
24//! Every `pub fn` in the module is a tool; its doc comment is what the model
25//! reads when deciding whether to call it.
26//!
27//! Build with the `riscv64imac-unknown-none-elf` target and
28//! `-Clink-arg=--emit-relocs`; the template's `.cargo/config.toml` carries
29//! both, and neither is optional.
30//!
31//! This crate declares no system harness of its own: what a harness can reach
32//! is whatever its host registered, and naming any of it here would be the SDK
33//! deciding what a host must serve. A harness running under the Crabtalk daemon
34//! adds [`berm-crabtalk`](https://crates.io/crates/berm-crabtalk), which
35//! declares that namespace — files, commands, HTTP, the runtime.
36

54// One boundary for the whole crate: `riscv.rs` makes real host calls, and
55// `stub.rs` is a host a test can stand in for. The split is about behaviour
56// rather than what will compile — `rvtime-guest` builds everywhere now — and it
57// is what lets a harness author run their tools without a guest around them.

66// Re-exported so a harness declares this SDK and nothing else. The `#[harness]`

87/// Traps instead of looping. An author's panic reaches the host as a
88/// breakpoint it can report, rather than hanging the thread that called in.
89///
90/// Only on the guest's own target — off it, the crate is an ordinary library
91/// linked into someone's tests, where std already supplies one.
92#[cfg(target_arch = "riscv64")]
93#[panic_handler]
94fn panic(info: &core::panic::PanicInfo) -> ! {
95    // Say where before dying. A harness author otherwise gets `guest executed
96    // ebreak` and nothing else, which is the difference between a minute and
97    // an afternoon.
98    if let Some(location) = info.location() {
99        abi::log(location.file());
100    }
101    guest::abort()
102}
