Run a harness’s tools natively, without a toolchain or a daemon.

A harness is an ELF that a host compiles and enters, which is a slow way to find out that a handler mishandles an empty string. Off the guest’s target the exports are ordinary functions and the buffers are ordinary memory, so a test can call one the way the host would — the same argument transfer, the same buffer limits, the same failure channel — and check what came back.

ⓘ
#[test]
fn echo_wraps_the_payload() {
    let out = berm_lang::test::call(berm_tool_echo, b"hi").unwrap();
    assert_eq!(out, br#"{"echo":hi}"#);
}
