Publishing and fetching harnesses as OCI artifacts.

A harness is one layer and no tarball, so the layer’s digest is sha256 of the ELF — the same hash berm ls prints, carrying the registry’s sha256: prefix. What the harness is rides in the config blob: the .berm.abi section verbatim, so a registry can be listed without pulling any image.
