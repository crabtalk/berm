#[harness] — turns a module of plain functions into a loadable harness.

The exports an ELF needs are ceremony: an entry point that keeps the linker from discarding the image, a heap handshake, a description the host reads at registration, and dispatch from a tool index back to a function. None of it is the author’s problem, so none of it is in their source.
