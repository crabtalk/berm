Declare the system harnesses a harness may call, emitting a stub for each.

ⓘ
berm_lang::harnesses! {
    namespace = "berm";
    mod fs {
        /// Read a file whole.
        fn read(path: &str) -> Vec<u8>;
    }
}

hosts! takes the same declaration and emits what a host registers under. Each side writes it in its own crate, and drift is caught on the first call: a renamed call hashes to a number nothing is registered for.
